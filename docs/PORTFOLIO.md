# Portfolio walkthrough

Aureon demonstrates a Flutter web/mobile workspace, a streaming .NET 10 gateway, and an authenticated Python audio service with durable jobs and versioned data. The strongest demonstration is a real end-to-end session. A [recorded guest fixture walkthrough](demo/README.md) with an actual exported master is included.

1. Open the welcome page in pearl mode. Preview one of five actual original compositions, then choose **Try the studio**.
2. Watch a real queued render progress through analysis, instrument stems, mixing, and completion. Play the measured waveform; point out that LUFS, peak, and spectrum are computed from decoded media.
3. Change the stem mix, mute/solo a part, apply a reviewed copilot suggestion, and render a new master. Compare current/previous masters with loudness matching.
4. Export a decodable WAV, MP3, stem/session ZIP, and portrait MP4. Show the corresponding durable job records and actual downloads.
5. Change the title/lyrics, show version history, restore an earlier state, and demonstrate a rejected conflicting revision rather than silent overwrite.
6. Generate original cover artwork. Publish the actual master, add a comment/like from a second account, then unpublish.
7. Invite a second account as editor and show an authenticated live save event. Revoke membership and demonstrate access denial; invitation codes rotate on removal.
8. Switch to graphite and reduce transparency/motion. Present phone/tablet layouts and the capability screen with optional services honestly gated.

> Built a Flutter music workspace with responsive themes, an ASP.NET Core 10 streaming gateway, and a Python DSP worker; implemented authenticated versioned sessions, durable render jobs, collaborative event replay, measured audio visualization, and WAV/MP3/stem/video exports.

Audio import analysis is approximate; import separation is spectral DSP; optional speech models generate speech rather than singing. Hosted deployment, native devices, paid providers, Postgres/Redis/S3 runtime tests remain explicit gates in the verification record.
